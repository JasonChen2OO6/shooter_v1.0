# SHOOTER!

## 游戏简介

SHOOTER! 是一款基于Qt框架开发的单人肉鸽（Roguelike）弹幕射击游戏。玩家将操控角色在弹幕中穿梭，击败源源不断的敌人，通过升级提升能力，最终挑战强大的BOSS，享受快节奏的射击与策略结合的乐趣。 

## 基本玩法 

- **操作方式**：使用键盘WASD键控制角色移动，鼠标控制射击方向，点击鼠标发射子弹 

- **核心目标**：击败敌人获取经验值，提升等级并选择强化属性或技能，最终战胜BOSS 

- **游戏循环**：每局游戏流程简短，支持快速重开，玩家可在每次游玩中探索不同的技能组合策略 

## 主要功能 

1. **角色系统**   

- 可通过升级提升5种基础属性（攻击间隔、移动速度、攻击力、子弹大小、击退力）   

- 解锁12种特殊技能（如子弹溅射、穿墙、击退减速等）

2. **敌人系统**   

- 包含3种普通敌人、1种精英敌人及2种BOSS   

- 不同敌人拥有独特的移动模式和攻击方式   

- BOSS战设有专属警告音效和特殊战斗机制 

3. **界面系统**  
- 标题界面：提供游戏启动入口   

- 游戏界面：显示生命值、经验值、等级及属性信息   

- 暂停界面：支持继续游戏或重新开始   

- 结束界面：显示本局经验值，支持重新挑战 

## 技术信息 

- 开发工具：Qt Creator 4.5.0 

- 开发语言：C++ - 运行平台：Windows 10 64位专业版 

- 版本：v1.0 

## 游戏亮点 

- 丰富的技能组合系统，支持多样化的战斗策略 

- 流畅的弹幕射击体验，考验玩家操作与反应 

- 渐进式难度设计，从普通敌人到精英怪再到BOSS战逐步提升挑战 

- 即时反馈的操作手感，包含命中特效和音效反馈 

## 已知问题 

- 在极少数未知情况下，可能出现所有敌人被快速移出屏幕的现象，将在后续版本修复 

## 操作提示 

- 按空格键开始游戏 

- 按ESC键暂停游戏 

- 暂停或结束界面按R键重新开始
